# 근태 현황 가져오기

## Outcome

사용자는 현황 제목 옆의 `가져오기` 버튼 한 번으로 로그인된 LG전자 근태 달력에서 정상근무시간과 누적근무시간을 가져와 기존 계산 입력에 반영할 수 있다.

## Scope

- 웹앱과 함께 설치하는 Chrome 확장 프로그램이 `https://attendance.lge.com/home/calendar/my-calendar`을 열거나 기존 탭을 사용한다.
- 확장 프로그램은 사용자의 기존 로그인 세션을 사용하며 로그인 정보는 읽거나 저장하거나 웹앱으로 전달하지 않는다.
- 정상근무시간과 누적근무시간은 근태 화면의 동일한 이름의 표시값에서 가져온다.
- 가져온 두 값은 기존 현황 입력을 갱신하고 기존 저장 및 계산 흐름을 그대로 사용한다. 남은 근무 일수는 기존 계산기의 자동 계산값을 유지한다.
- 가져오기가 완료되면 사용자가 결과를 바로 확인할 수 있도록 근무시간 배분 계산기 탭을 활성화한다.
- 가져온 값은 사용자가 직접 수정할 수 있다.

## User-visible behavior

- 현황 제목 옆에 `가져오기` 버튼이 표시된다.
- 가져오는 동안 버튼은 비활성화되고 진행 중임을 표시한다.
- 확장 프로그램이 없으면 설치가 필요하다는 안내를 표시한다.
- 근태 로그인이 필요하면 열린 근태 페이지에서 로그인한 뒤 다시 가져오도록 안내한다.
- 필수 값을 찾지 못하거나 달력을 해석하지 못하면 기존 입력값을 변경하지 않고 오류를 표시한다.
- 성공하면 정상근무시간과 누적근무시간을 함께 갱신하고 계산기 탭으로 돌아와 완료 안내를 표시한다.

## Acceptance criteria

1. `가져오기`를 누르면 근태 달력 URL이 새 탭에서 열린다.
2. 근태 화면에 `정상근무시간 160시간`, `누적근무시간 81시간 30분`이 표시되면 각각 `160`, `81`, `30`이 현황 입력에 반영된다.
3. 가져오기 전후로 남은 근무 일수 값은 변경되지 않는다.
4. 두 값 중 하나라도 신뢰성 있게 추출하지 못하면 어떤 현황 값도 부분 갱신하지 않는다.
5. 가져오기가 성공하면 근무시간 배분 계산기 탭이 활성화된다.
6. 가져온 값으로 기존 부족/충족/초과 계산 결과가 즉시 다시 계산된다.
7. 로그인 자격 증명이나 근태 페이지 전체 내용은 저장하거나 외부 서버로 전송하지 않는다.

## Settled constraints and rationale

- 일반 웹페이지는 다른 출처의 페이지 DOM을 읽을 수 없으므로 Chrome 확장 프로그램을 사용한다.
- 근태 시스템은 읽기 전용으로 다루며 기록이나 수정 동작을 하지 않는다.
- 추출 실패 시 추측한 값으로 계산하지 않고 사용자에게 실패를 알린다.

## Assumptions

- 사용자는 확장 프로그램을 개발자 모드에서 설치할 수 있다.
- 근태 화면은 정상근무시간과 누적근무 항목 이름 및 시간 단위를 사용자에게 보이는 텍스트로 제공한다.

## Off-limits

- 근태 로그인 자동화와 자격 증명 저장
- 근태 데이터 작성 또는 변경
- 서버를 통한 사용자별 근태 데이터 저장
- Chrome 외 브라우저 확장 프로그램 배포

## Deferred points and risks

- 실제 화면 캡처를 기준으로 시간 표기를 지원하지만, 사내 페이지의 향후 DOM 또는 문구 변경 시 추출 규칙을 조정해야 할 수 있다.
- 사내 배포를 위한 Chrome 확장 프로그램 서명과 관리 정책은 별도 결정이 필요하다.
